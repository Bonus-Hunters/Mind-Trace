# Mind Trace

## Getting Started

### Prerequistes

Before you begin, ensure that your virtual environment is using the correct Python version.
If you're not working with virtual environments, make sure the matching Python interpreter is installed on your system.

#### Python

Required Version: 3.13

#### Poetry

Install Poetry using:

```
> pip install poetry
```

After installing Poetry, install all required dependencies:

```
> poetry install
```

```
> pip install -r requirements.txt
```
